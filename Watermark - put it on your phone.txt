WATERMARK: GET IT ON YOUR PHONE (free, about 5 minutes, one time)

You're putting the file on your own free GitHub page. Then it's a link you open in Safari, the same as now.
Easiest on a computer, but it works in Safari on an iPhone too.

1. RENAME THE FILE
   Rename Watermark.html to index.html
   (On iPhone: save it to the Files app, press and hold it, then Rename.)

2. MAKE A GITHUB ACCOUNT
   Go to github.com and sign up (free). Remember your username.

3. MAKE THE REPOSITORY
   Tap the + (top right), then New repository.
   - Repository name: watermark
   - Set it to Public (the free page needs this)
   - Tap Create repository

4. UPLOAD THE FILE
   On the next page, tap "uploading an existing file".
   Choose your index.html, then tap Commit changes at the bottom.

5. TURN ON THE WEB PAGE
   In the repository, go to Settings, then Pages (left menu).
   - Source: Deploy from a branch
   - Branch: main, folder: / (root)
   - Tap Save
   Wait 1 to 2 minutes.

6. YOUR LINK
   https://YOUR-USERNAME.github.io/watermark/
   (Use your GitHub username, in lowercase.)

7. PUT IT ON YOUR HOME SCREEN
   Open the link in Safari, tap Share, then Add to Home Screen.
   It sits on your home screen like an app.

If a button is missing on your phone: in Safari, tap "aA" in the address bar, then Request Desktop Website.

----------------------------------------------------------------
USING CLAUDE INSTEAD

Claude Code on a computer can do steps 1 to 6 for you. Put Watermark.html in a folder, open Claude Code in that folder, and paste this:

   Publish Watermark.html in this folder as a GitHub Pages site on my account.
   Rename it to index.html, create a public repo called "watermark",
   push it, turn on Pages from the main branch root, and give me the
   https://<username>.github.io/watermark/ link once it loads.

It will ask you to log in to GitHub once (it runs "gh auth login"; just follow the prompts).
Then do step 7 on your phone.

The Claude phone or web app can't click through GitHub for you. Paste these steps into it and it will walk you through them.
